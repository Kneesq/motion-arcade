# Motion Arcade 动感街机

## [▶ 开始游戏](https://kneesq.github.io/motion-arcade/)

在手机 GitHub App 点上面的「▶ 开始游戏」即可进入游戏大厅。选好人数和镜头后，点「开启相机游玩」。如果 App 内网页无法请求相机，可从页面菜单选择用 Safari 或 Chrome 打开。

这是一个原生 HTML、CSS 和 JavaScript 游戏厅。三个游戏共用手机的镜头、玩家设置和本地姿态识别模型。整包是静态网页，可以直接交给静态网站服务器，无需编译或安装前端依赖。

## 手机上打开

把 `dist` 设为静态网站的根目录，使用手机信任的 HTTPS 网址访问。保留 `assets` 和 `vendor` 的目录结构，并让服务器以 JavaScript 的 MIME 类型提供 `.mjs`，以 `application/wasm` 提供 `.wasm`。普通局域网 HTTP 地址可用来触控试玩，手机相机需要安全上下文。

电脑本机如装有 Python 3，可在包含此说明的目录运行以下命令，然后在同一台电脑打开 <http://localhost:8000>。

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

## 体感游玩

1. 在大厅或开局设置点「声音开／关」即可切换音乐和音效，浏览器会记住选择。选择游戏、1 至 4 位玩家、前置或后置镜头。可选双手两点，或双手和双脚四点。
2. 点「开启相机游玩」，允许相机权限。把手机放稳，让所有玩家并排站直，识别齐全后会自动开始。多人横屏游玩更容易入镜。
3. 气球爆破每局 45 秒。可选择从上方落下的气球或透明泡泡。2 至 4 人开启「指定颜色」后，每人选自己的颜色。击破自己的目标加 10 分，碰错扣 5 分，目标留给对应的玩家。
4. 节拍舞台提供 14 个动作，包括双手左滑、双手右滑、双手上下摆和原地跳跃。两个滑动动作按画面方向判断，双手上下摆需完成上、下两段动作。跟着领舞在节拍上完成动作即可得分。在游玩设置中可选本机歌曲、调节 BPM、每步拍数和前奏，并随机或手动编舞。歌曲和编排保存在当前浏览器，内置节拍也可直接开玩。
5. 冒险跑酷有云端天空、萤光森林和珊瑚海底三个主题，沿途随机出现该场景的动物。单人使用一条全屏跑道，双人各跑一条。合作模式下两人遇到相同的障碍，共同通过每关四道障碍中的两道即可前进。对战模式下两人各有一组挑战，最后比较总分。通过障碍得 15 分，金币得 5 分，星星得 10 分。双人触控试玩有两组按钮，电脑也可用 WASD 操作玩家 1、方向键操作玩家 2。

相机画面和歌曲都在本机处理。进入后台会暂停，退出本局会释放镜头。在没有相机的设备上，点「触控试玩」也可以玩三个游戏。

## 投屏到电视

让手机和电视连上同一 Wi-Fi。iPhone 使用控制中心的「屏幕镜像」，选择支持 AirPlay 的电视。Android 使用 Google Home，选择支持 Google Cast 的电视并投放屏幕。连接后回到浏览器，镜头仍由手机负责。大厅和游戏中的投屏按钮提供操作说明。

## 修改游戏

- `dist/index.html`、`dist/style.css`、`dist/app.js` 提供大厅、设置、投屏说明和回合控制。
- `dist/arcade.js` 处理气球与泡泡，`dist/runner.js` 处理跑酷场景、收集物和竞赛。`dist/game-options.js` 提供开局选项。
- `dist/runner-world.js` 绘制主题与动物，`dist/sound.js` 合成气球爆破、泡泡破裂、碰错颜色、金币和星星五种音效。
- `dist/dance.js`、`dist/dance.css` 提供舞步、歌曲和编舞器，`dist/dancers.js` 绘制随拍摆动的角色。
- `dist/tracker.js` 处理相机、玩家编号、手脚位置及动作判断。模型与第三方许可信息随附于 `dist/vendor/mediapipe/`。
